# Симулятор движения электрического заряда

## Описание проекта

Программа предназначена для моделирования движения электрического заряда в электрическом поле другого неподвижного заряда.

В основе проекта лежит математическая модель взаимодействия электрических зарядов. Расчёт траектории выполняется численными методами с последующей визуализацией результатов.

## Основные возможности

- Задание параметров электрических зарядов и начальных условий.
- Расчёт траектории движения заряда.
- Визуализация движения в двумерной плоскости.
- Отображение результатов моделирования.
- Проверка сохранения механической энергии.

## Технологии

- **Backend:** C#, ASP.NET Core.
- **Frontend:** HTML, CSS, JavaScript.
- **Визуализация:** Plotly.js / Canvas.
- **Тестирование:** xUnit.

## Распределение обязанностей

**Руководитель проекта:**

- Реализация численного метода RK4.

- Создание пользовательского интерфейса.
- Реализация ввода параметров.
